# 선화 스타일 플레이어 64x64

- 개별 PNG 32장, 각 파일 64x64, 투명 배경.
- Carry: 붓을 세워 들기. Draw: 붓을 바닥으로 내려 그리기.
- 각 모드에 Down, Left, Right, Up 방향. 방향마다 Idle, Run_01, Run_02, Run_03.
- 같은 방향 내에는 동일 축소 비율을 적용하고 바닥 기준을 맞췄습니다.
- 선화용 부드러운 경계 유지: Bilinear, 무압축, Mipmap 꺼짐, PPU64.
- 씬·프리팹·Animator는 변경하지 않았으며 실행 애니메이션에는 아직 연결하지 않았습니다.
- 전체 보기: ArtDrafts/Painter_Line64_AllFrames.png. 위 4행 Carry, 아래 4행 Draw. 각 모드의 행은 Down/Left/Right/Up, 열은 Idle/Run01/Run02/Run03.
- 생성형 이미지 기반 동작 초안입니다. 실제 루프 속도와 연결 자연스러움은 Animator에서 조정·검증해야 합니다.

제작: imagegen 내장 도구. 프롬프트 세트: 기존 굵고 둥근 선화 캐릭터 정체성 보존, 모자 없는 코랄 몸·크림 앞치마·붓; 방향별 동일 방향 4포즈(정지/이동3), 일반 붓 위·그리기 붓 아래; 4칸 단일행, 투명 배경, 그림자와 텍스트 제외. 픽셀아트가 아닌 부드러운 선화 스타일로 생성하고 개별64px PNG로 축소 저장했습니다.
