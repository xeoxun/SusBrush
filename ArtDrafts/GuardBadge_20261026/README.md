# 경비원 배지 레이어

Assets/Sprites/Characters/Painter_Line64_Layers/GuardBadge/Carry 및 Draw에 32장이 있습니다.
모든 이미지는 64x64, 중앙 피벗, PPU64, 투명 배경입니다.
같은 이름의 Fixed/Tint 프레임과 같은 위치·크기로 겹치고 배지 Renderer를 Fixed보다 높은 Sorting Order에 둡니다.
예: Carry_Down_Run_01_Fixed + Carry_Down_Run_01_Tint + Carry_Down_Run_01_GuardBadge.
경비원 표시 여부와 애니메이션 클립 연결은 아직 추가하지 않았습니다.
Fixed와 Tint 원본은 변경하지 않았습니다.
